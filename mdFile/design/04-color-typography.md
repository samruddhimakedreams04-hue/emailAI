## Color Palette (Suggested)

| Token | Hex | Usage |
|-------|-----|-------|
| Primary | `#1a73e8` | Buttons, links, active nav (Google blue) |
| Primary hover | `#1557b0` | Button hover |
| Background | `#f8f9fa` | Page background |
| Surface | `#ffffff` | Cards, panels |
| Text primary | `#202124` | Headings, body |
| Text secondary | `#5f6368` | Metadata, timestamps |
| Border | `#dadce0` | Dividers, inputs |
| Success | `#34a853` | Success messages |
| Warning | `#fbbc04` | Urgent email badge |
| Error | `#ea4335` | Errors, delete actions |
| AI accent | `#8e24aa` | AI chat bubble, agent badge |
